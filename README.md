# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

### 超迟到旁路夹具（主链）

架构：**乙 · 可升格暂存**（全局只贯彻这一种）。
入流时水位已越过「窗止 + 允许迟到」→ 事件只写旁路匣、绝不改该窗合计；旁路匣保留原窗键载荷；
升格须显式调用，升格成功后才按升格口径改原窗并补一笔撤回单。

```bash
# 1. 抬水位越过旁路界后再推原窗事件：窗不变、旁路可查
灌「准时热度样例」→「迟到修正样例」→「超迟到旁路样例」→「抬水位越界样例」→「原窗超迟事件样例」
GET  /api/旁路匣/只读/X2        # 水位>旁路界、窗止、valid、升格是否可调用、是否改窗

# 2. 调升格
POST /api/旁路匣/升格 {"事件编号":"X2"}
#   乙：成功，改原窗 12:00 并补撤回单（升格改历史窗=true）
#   对照甲（永久隔离，不在本工程启用）：接口必须拒绝、历史窗永不被该事件改动

# 3. 旁路与迟到修正并发：不得「窗被改 + 旁路同时成功」
#   两个入流同一事件时间窗交错时，入流闸 BEGIN IMMEDIATE 串行化；抢锁失败整笔回滚（失败闭）
#   夹具：并发旁路侧样例 / 并发迟到侧样例

# 4. 旁路后直接打迟到写（同一事件编号）：界戳接管迟到写
#   铺底后灌「旁路后迟到写样例」→ X1 再次入流
#   乙（本工程）：累计不变、戳态=待解旁路、待办可查；持解旁路工单方可改正式累计
#   甲（对照，不在本工程启用）：整票拒绝、戳态仍为旁路、无待办、累计不变
GET  /api/核证/旁路界戳/核验        # 只读核证：戳空/双记/戳号顶替 三项硬约束
POST /api/旁路匣/解旁路 {"事件编号":"X1","工单号":"…"}
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 撤回单 | 已关闭窗被允许迟到事件修正（含旁路升格补单） |
| 旁路匣 | 超允许迟到：只写匣、不改窗；保留原窗键载荷 |
| 旁路界戳 | 旁路成功后同票打戳（事件编号、窗键、水位快照、旁路界、戳号、戳态） |
| 旁路待办 | 乙口径下迟到写命中界戳时落「待解」工单，持工单方可解旁路 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 ↔ 旁路匣/界戳绑定 |

## 旁路界戳接管迟到写

硬约束：**禁止旁路成功戳空；禁止同事件既在匣又改累计；禁止戳号被邻事件顶替。**

旁路写闸、迟到写闸、旁路匣、热度窗、窗互证协同：

- 旁路写闸（入流时水位已越过「窗止 + 允许迟到」）：落匣成功即在**同一票**打界戳；
  戳要素任何一项缺失直接抛错，整批回滚，绝不「匣成、戳空」。
- 迟到写闸（同事件编号再次出现）：命中已有界戳 → 按全局架构消化，**绝不再改正式累计**。
- 界戳核证只读接口：只核验不写库，逐项输出三条硬约束是否被破坏。

本工程全局选 **乙 · 戳态机升级**，两口径对「旁路后直接打迟到写」的结论可分：

| | 甲 · 界戳一票否决 | 乙 · 戳态机升级（本工程） |
| --- | --- | --- |
| 迟到写命中界戳 | 整票拒绝 | 不改正式累计，戳态推进 |
| 戳态 | 保持「旁路」 | 推进为「待解旁路」 |
| 待办 | 不落 | 落「待解」工单 |
| 改正式累计 | 永不可以 | 持解旁路工单解后可以 |

`GET /api/核证/旁路界戳/核验` 同时返回当前架构与两口径的 `迟到写遇戳` / `戳态是否推进` /
`是否落待办` / `解旁路`，便于对照断言。

## 接口（超迟到旁路）

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/旁路匣/只读` | 旁路只读列表（事件编号、水位、窗止、旁路界、界戳/戳态、升格/解旁路是否可调用、是否改窗、valid） |
| GET | `/api/旁路匣/只读/{event_id}` | 单条只读 |
| GET | `/api/旁路匣/口径` | 当前架构与甲/乙对照结论（含界戳口径） |
| POST | `/api/旁路匣/升格` | 显式升格 `{事件编号}`；乙成功改原窗，甲拒绝；戳态=待解旁路时拒绝 |
| POST | `/api/旁路匣/解旁路` | 持解旁路工单解 `{事件编号, 工单号}`；仅乙可改正式累计 |
| GET | `/api/旁路匣/待办` | 旁路待办工单列表（可按事件编号过滤） |
| GET | `/api/核证/旁路界戳/核验` | **旁路界戳核证只读接口**：硬约束逐项核验，不改任何状态 |
